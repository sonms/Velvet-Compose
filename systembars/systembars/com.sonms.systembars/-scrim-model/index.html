class ScrimModel(val lightScrim: Color, val darkScrim: Color)

3버튼 내비게이션 뒤에 시스템이 깔아 주는 반투명 스크림의 근사값입니다. 실제 값은 플랫폼 내부 값이라 기기에 따라 다르면 직접 지정하세요.
