SystemBarsConfig

@Immutable
data class SystemBarsConfig(val intervalMillis: Long = 300, val lowThreshold: Float = 0.45f, val highThreshold: Float = 0.55f, val contrastEnforced: Boolean = true, val scrimModel: ScrimModel? = ScrimModel.AndroidxDefault)

SystemBarsHost 의 동작을 조정합니다. Tuning for SystemBarsHost.

Parameters

intervalMillis

샘플 사이의 최소 간격(ms). 낮출수록 반응이 빠르지만 스크롤 중 프레임 비용이 늘어납니다. / Minimum time between pixel samples; lower reacts faster but costs more frame time while scrolling.

lowThreshold

이 휘도보다 낮아지면 밝은 배경에서 어두운 배경으로 전환합니다 (0..1). / Luminance below which a light background flips to a dark one.

highThreshold

이 휘도보다 높아지면 어두운 배경에서 밝은 배경으로 전환합니다 (0..1). 두 임계값 사이에서는 직전 값을 유지합니다(히스테리시스). / Luminance above which a dark background flips to a light one; between the two the previous value is kept.

contrastEnforced

Window.isNavigationBarContrastEnforced 값 (API 29+). / Value for Window.isNavigationBarContrastEnforced (API 29+).

scrimModel

3버튼 내비바 보정에 쓰는 스크림. null 이면 보정을 끕니다. contrastEnforced 가 true 일 때만 적용됩니다. / Scrim used to correct the 3-button navigation bar; null disables it. Applies only when contrastEnforced.
