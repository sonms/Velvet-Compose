systembars/com.sonms.systembars/BarPaint

BarPaint

@Immutable
sealed interface BarPaint

시스템 바 영역을 노드가 직접 칠할지, 무엇으로 칠할지 나타냅니다. 기본은 None (칠하지 않음, 투명). Whether the node paints the system bar area itself, and with what. The default is None (transparent).

칠하기는 Window.statusBarColor 같은 윈도우 속성이 아니라, 노드가 콘텐츠 위 바 영역에 사각형을 한 번 더 그리는 방식입니다. 그래서 모든 API 레벨에서 같게 동작하고, 색을 애니메이션할 수 있습니다. 바 영역과 겹치는 노드 범위에서만 칠해지며, 해당 바를 결정하는(스택에서 이기는) 노드만 칠합니다.

Painting draws a rectangle over the content in the bar area (not a window property like Window.statusBarColor), so it behaves the same on every API level and the color can be animated. It only paints where the node overlaps the bar, and only the node that currently decides that bar (the stack winner) paints.
